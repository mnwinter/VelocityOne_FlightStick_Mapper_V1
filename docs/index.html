Before your first flight

Connect. Map. Verify.

Release downloads include the Python/Qt/SDL runtime, VIIPER backend and signed USBIP installer. Read the Windows and Microsoft runtime prerequisites.

Ace Combat 8 is the only game tested so far. All other game presets are untested. This is a preview. The mapper itself is unsigned. Verify the release checksum and review setup instructions. Virtual Xbox output needs an explicit administrator-approved USBIP driver installation. Proposed layouts require testing in your game; V2, Flightdeck and other HOTAS models are not claimed compatible.
  1. Connect the original V1 in PC mode and close other mappers.
  2. Open Tools → Driver setup / dependencies for virtual Xbox output.
  3. Select a game and preset. Learn your controls, check direction and save your layout.
  4. For thumbwheel up/down, set the stick OLED to Trim Wheel → Response → Digital Buttons, then Learn each direction separately. Wheel press is Button 15.
  5. Start output, verify the virtual controller in Windows, then check your game's bindings.

Ctrl+Alt+F12 stops output while the UI is responsive. Keyboard/mouse injection and virtual controllers may be restricted by individual games.
